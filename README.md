# QA Agentic Lab

Laboratorio público de **automatización de pruebas con agentes de IA**, gobernado por **especificación (SDD con
OpenSpec)**.

Sobre una tienda online pequeña construida para la ocasión, **La Tienda en Casa**, el laboratorio enseña de principio a
fin:

- **Proceso y gobierno:** cada funcionalidad nace como especificación; de ella salen el código, los escenarios Gherkin
  y las pruebas, con trazabilidad de punta a punta y revisión humana de todo cambio.
- **Herramientas:** pruebas funcionales, de API, accesibilidad, regresión visual, rendimiento, carga y seguridad en un
  pipeline de GitHub Actions por etapas.
- **IA con límites:** un equipo de agentes de QA que diseña, automatiza, repara, clasifica e informa. Las pruebas y las
  *quality gates* deciden; los agentes no.
